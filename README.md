# ウォーキングX

スマートフォンのブラウザで使う、駅や現在地から出発する散歩ルート作成プロトタイプです。

公開URL: https://gomatime.github.io/walkday/ （スマートフォンでは現在地も使えます）

## 起動方法

1. `walkday` フォルダーを開きます。
2. `index.html` をブラウザで開きます。
3. 出発駅を検索して候補を選び、目標・寄り道カテゴリを指定して「おすすめルートを作る」を押します。

ブラウザやネットワーク環境によっては、ローカルHTMLからの外部通信が制限されることがあります。その場合は `walkday` フォルダーでローカルHTTPサーバーを起動してアクセスしてください（例: `python -m http.server 8000`）。

## 現在の機能

- 日本国内の駅名検索または現在地からの出発、出発地に戻る／別の駅へ向かうルート
- 距離・歩数・消費カロリーの目標指定（体重は任意）。実際の徒歩距離が目標の±15%に収まるよう、寄り道先の組み合わせを自動調整
- カフェ、飲食店、サウナ、公園、フォトジェニックスポット（展望・名所・アート・史跡）、神社・寺の周辺候補検索
- 徒歩ルート、概算距離・時間・歩数・カロリーの地図表示。同じ道を往復する区間は破線と注意書きで表示
- GPSによる地図上の経路案内（現在地の追従、曲がり角・寄り道先までの距離、音声案内、到着通知、ルート逸脱時の再計算、案内中の画面消灯防止）
- Google Mapsでのルート表示と、施設の口コミ検索
- スマートフォン表示に対応したレイアウト

## データについて

背景地図には国土地理院の地理院タイル、施設候補にはOpenStreetMapのデータ、駅検索にはNominatim、候補検索にはOverpass API、徒歩経路には公開OSM徒歩ルーティングサービスを使用します。いずれも公開サービスの利用制限や稼働状況に左右されます（候補検索は応答がない場合にミラーサーバーで再試行します）。安定運用や利用者数の多い公開には、各サービスの利用ポリシー確認と専用APIへの移行が必要です。

無料のOpenStreetMapデータには店舗の口コミ評価や話題性の統一データがないため、この試作版は評価・人気順を装いません。寄り道候補は、目標距離に合う組み合わせのうち、同じ種類に偏らないものを選びます（選んだカテゴリ数に応じて最大5か所）。各候補の「口コミを見る」から地図上で評判を確認できます。評価点・口コミ件数での絞り込みや人気順を実装する場合は、対応する店舗情報APIとその利用条件・費用を別途選定する必要があります。

歩数（1kmあたり約1,300歩）と消費カロリー（体重を用いた概算）は目安です。実際の経路や所要時間は歩行速度、信号、施設の営業状況などで異なります。

現在地の取得はブラウザの位置情報を使うため、PCで直接開いたページ（file:// や localhost）か、https:// で公開したページでのみ使えます。スマートフォンから `http://192.168.x.x` のようなアドレスで開いた場合は使えません。

経路案内はブラウザ上で動くため、画面を消したり別のアプリに切り替えたりすると現在地の更新が止まります（案内中は画面が自動で消えないようにしています）。音声案内はスマートフォンのマナーモードや音量設定によって聞こえない場合があります。
